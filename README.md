# Отбор

Своя лента новостей в духе Google Discover — без рекламы и без привязки к истории поиска.
Показывает материалы только из выбранных источников и только по выбранным темам.

**Открыть:** https://vsamolet.github.io/otbor/ — на телефоне: меню браузера → «Добавить на главный экран».

## Как устроено

- `config.json` — стартовые темы, стоп-слова и источники (RSS).
- Каждые 15 минут таймер на Cloudflare Workers (`timer-worker.js`) запускает GitHub Actions (`.github/workflows/feed.yml`),
  а тот — `scripts/build-feed.mjs` (собственное расписание GitHub — только запасное: GitHub запускает его с опозданием на часы):
  скачивает все источники, разбирает и публикует `feed.json` вместе с приложением в ветку `gh-pages`.
- Приложение (`index.html`, `parse.js`) забирает `feed.json` со своего же сайта и фильтрует по темам прямо на телефоне.
  Темы, источники и фильтры можно менять в настройках приложения — они хранятся на устройстве.
- Новые источники и темы, добавленные в `config.json`, появляются в приложении сами при следующем обновлении.
- Источники, добавленные с телефона, загружаются через публичные CORS-прокси; на случай их сбоев есть `cors-worker.js`
  (свой прокси на Cloudflare Workers).

## Перевод

Иностранные заголовки и анонсы переводит сборщик через Google Translate (пакетами, с повторами).
Если Google ограничит серверы GitHub, видимые карточки переводит сам телефон. Статьи открываются через translate.google.com.

## Правила тем

- слово ищется по началу: `девелоп` → «девелопер», «девелопмента»;
- короткие слова (до 3 букв) и слова с `!` на конце — целиком;
- аббревиатуры заглавными (`ИИ`, `PR`, `IT`) — с учётом регистра;
- фраза `рекламн агентств` → «рекламное агентство»;
- поле «и обязательно одно из» сужает тему: нужно совпадение и с основными словами, и с одним из этих.
